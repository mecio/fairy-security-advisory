# fAIry advisory directives

These directives are specific to the fAIry Security Advisory workflow. They
are decision rules, not report templates. Do not copy project identities,
paths, versions, findings, or other local evidence into them.

Always read these files before starting an advisory check:

- [general.md](general.md)
- [applicability.md](applicability.md)

Read the additional files selected by this matrix. If more than one row
applies, read all of them.

| Activity | Additional directive |
| --- | --- |
| Collect, inspect, or assess advisory sources | [source-coverage.md](source-coverage.md) |
| Produce or merge a daily report, summary, follow-up, or routed dossier | [consolidation-and-output.md](consolidation-and-output.md) |
| Produce a routed coordinator result or coverage receipt | [consolidation-and-output.md](consolidation-and-output.md) |
| Discuss a selected finding or research one technology version in AI chat | [interactive-assistant.md](interactive-assistant.md) |

The directives complement the canonical repository instructions. If a source,
version, prerequisite, or production fact is unverified, state that limitation;
do not invent it and do not silently omit the candidate it affects.
